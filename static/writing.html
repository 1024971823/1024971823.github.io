把想法写下来，就可以发布。

在网页里写文章、添加图片、预览排版。无需打开工程或修改代码。

发布一篇文章

  1. 点击 写文章，使用你的 GitHub 账号登录。
  2. 在标题框输入文章标题，在正文框写内容。可用工具栏插入标题、加粗、链接、列表和代码块；图片可以直接拖入正文框。通过 Preview 预览排版。这是带预览的 Markdown 编辑器，不是 Word 式所见即所得编辑器。
  3. 确认右侧 Labels 中有 blog 标签。写文章入口会预选；若没有，点击 Labels 选择 blog。
  4. 点击 Create 或 Submit new issue。文章为公开内容；通常几分钟后就会出现在博客首页。

保存草稿、修改和下架

  • 草稿：在发布前移除 blog 标签，保存后不会进入博客；但 GitHub 上的 Issue 本身仍是公开的，私密草稿请先写在自己的笔记应用。
  • 修改：打开 管理文章，进入对应文章，点击正文右上角的菜单 → Edit。保存后自动更新。
  • 下架：移除 blog 标签或关闭该文章的 Issue；重新添加标签并保持 Issue 打开即可重新上架。
发布后还没更新？打开 发布进度，等待最新一次 Publish blog 显示绿色勾号，然后刷新博客。
